# Profile motion and camera views (Play running and fighting)

Curated frames from frame-exact 60 Hz Lab captures
(`scripts/capture-motion-quality.mjs`, software WebGL, 1280×720, stepped one
fixed frame at a time). Full captures live under ignored `work/qa/`.

- `running-before-after.jpg`: before, the front-view cut-out puppet shuffled
  sideways in a bow-legged squat; after, the side-view rig runs with a real
  stride (knee drive, heel recovery, flight phase, arm swing back past the hip).
- `fighting-before-after.jpg`: before, two camera-facing puppets in wide squats
  with a mirrored shirt print; after, a profile guard, punches and hit-stop,
  with the left-facing fighter in the rear-three-quarter garment view.
- `view-turns.jpg`: runners face the camera at the start, flip edge-on and
  run in profile; the winner turns back to the camera to celebrate.
