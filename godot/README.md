# Arena Godot client (experiment)

A Godot 4.7.2 presentation client for *Will You Be My Hero? Arena*, built on art
regenerated for Godot. It plays the frozen Phaser build's immutable recordings; it does
not simulate. Start with [`EVALUATION.md`](EVALUATION.md) (charter and thresholds),
[`AGENTS.md`](AGENTS.md) (rules), [`PROBES.md`](PROBES.md) (measured Godot facts) and
[`art/SPEC.md`](art/SPEC.md) (rig-ready art spec).

```sh
bash godot/tools/bootstrap.sh && bash godot/tools/run_tests.sh
```
