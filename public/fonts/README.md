# Display web font

`anton-latin-400-normal.woff2` is Anton Regular (latin subset), copied
unchanged from the `@fontsource/anton` 5.3.0 npm package
(`files/anton-latin-400-normal.woff2`; upstream
https://github.com/googlefonts/AntonFont). It is licensed under the SIL Open
Font License 1.1; the license text ships alongside as `Anton-OFL.txt`.

SHA-256: `d0fa07ff63dd60cbc0e2f58e29c802dca2a5ae0276c999f59c6111ab7bbaec3b`

It backs the display stack `Impact, 'Anton', 'Arial Narrow', sans-serif`
(declared with `@font-face` in `app/globals.css`, and used by the canvas HUD
through `ARENA_THEME.font`) on systems without Impact. No runtime dependency
is installed for it.
